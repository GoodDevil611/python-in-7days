🐍 Day 1 - What is Python?

💡 What is Python?

Python is a programming language used to create games, websites, and even AI.

It is very easy to learn and looks like normal English.

🧪 Your First Program

print("Hello World")

This line tells Python to display text on the screen.

🤔 How it works

print() → shows something on screen

"Hello World" → the text we want to show
